# Engineering College — Static Website

Public brochure-style static website for Engineering College built using HTML5, CSS3, Bootstrap 5, and Vanilla JS.

## Page Map
- `index.html` — Hero section & institution highlights
- `about.html` — College background & offered engineering programs
- `admissions.html` — Application process steps & tuition fees table
- `student-life.html` — Campus events & interactive news loader
- `contact.html` — Contact channels, contact form with anti-spam check
- `register.html` — Advanced registration form with client-side validation

## Key Features & JS Interactivity
- **Color Palette:** High-contrast dark, yellow, and white theme.
- **Responsive Layout:** Mobile-first architecture using Bootstrap 5 grid & collapsible navbar.
- **Forms & Validation:** 
  - Advanced registration with strict client-side validation, password matching, and agreement checks.
  - Basic contact form featuring a simple mathematical anti-spam verification (`4 + 5 = 9`).
- **Interactive Enhancements (JS):**
  - Progressive "Load More News" toggle on the Student Life page.
  - Real-time password verification on the Registration page.

## Known Limitations
- Static frontend only (no database persistence for form submissions).
